# 地表データ

方位盤の背景に描く地表（森林・水域）のデータ。[yamamuki-data](https://github.com/shohei0205/yamamuki-data) が配る SQLite を端末に置いて使う（Android・iOS）。

yamamuki-data が正式に公開するまでは、開発用のビルド（Android の debug、iOS の Debug）だけで出す（`Features.SURFACE` / `Features.surface`）。方位盤の左下の地表データのボタン（設定の歯車の上）から開く選択画面で、方位盤の背景に描くものを選ぶ。

- データは ESA WorldCover 2021 から作った森林・水域と、国土地理院の標高タイルから作った陰影。Web メルカトルのタイル画像を収めた SQLite で、全国が 1 ファイル。アプリが読む種類は core の `SurfaceDataset`。収録するズームの違うファイルに分けて配り、`esa-worldcover-z9`（ズーム 5〜9、約 17 MB）、`z10`（5〜10、約 42 MB）、`z11`（5〜11、約 127 MB）、`z12`（5〜12、約 390 MB）がある。ズームが大きいほど、近くを拡大したときに細かく見える。受け取れる大きさの上限は 500 MB。
- 読む manifest は、山データと同じカタログ `catalog.json` の、その種類の `stable`（開発用のビルドは `dev`、無ければ `stable`）で決める。カタログにその種類が無いあいだは、選択画面に「利用できる地表データはありません。」と出す。
- 地表データの選択画面（山データの選択画面とは別）では、「表示しない」、オフラインデータ（yamamuki-data の地表データ）、オンラインデータ（地理院タイル。下の「地図（国土地理院）」）から 1 つを選ぶ。選んだものに「使用中」の印を付ける。設定の `showSurface`・`surfaceDataset`・`onlineSurface` に覚え、設定画面には地表の項目を置かない。
- 「オフラインデータ」の見出しには、試験的に配っていることを示す「試験版」の印を付ける。節には取得済みの種類とカタログにある種類を並べる。行には名前、「試験版」「使用中」「更新あり」の印、リリース日・取得日・大きさを出す。節の最後に「陰影を表示」のスイッチを置く。
  - 取得していない種類を選ぶと、リリース日と大きさを見せてダウンロードするかを聞く。取り込めたら、その種類を表示する。
  - 新しい版があるときは「更新」、取得済みなら「削除」のボタンを出す。表示している種類を削除すると、「表示しない」に戻す。
  - ダウンロード中は進み具合（%）を出す。
- データ本体はメモリに載せず、ファイルへ流しながら受け取る。別名で保存し、サイズと SHA-256、SQLite の中身（`PRAGMA application_id` と `user_version`、manifest に書かれた地表のデータセットとズームの段があるか）を確かめてから置き換える。途中で失敗しても前の版はそのまま残る。
- 置き場所は、Android が `noBackupFilesDir/surface-data/<種類>/`、iOS が Application Support の `surface-data/<種類>/`（バックアップから除外）。取り込んだ manifest も残し、出典の表示に使う。山データの DB（Room）には入れない。
- 既定は「表示しない」。
- 方位盤には、表示している場所を中心にした北が上の画像（一辺 1280 画素）を 1 枚作り、端末の向きの分だけ回して地面に貼る。
  - タイルは Web メルカトル、方位盤は現在地からの距離と方位の平面図なので、タイルをそのまま貼ると継ぎ目がずれる。画像の中の位置を山と同じ計算（中心からの距離と方位）で決めて並べ直すので、山とずれない。
  - 画像の半径は表示範囲の 1.8 倍以上の段階（√2 倍刻み）にする。画面が画像からはみ出すとき（大きく動かしたとき、遠くまで表示したとき）と、拡大して粗くなりすぎたときだけ作り直す。拡縮や移動の途中では作らず、0.2 秒落ち着いてから作る。作っている間は前の画像を貼ったままにする。
  - 読むズームは、画像の 1 画素より細かい段のうち最も粗い段。元の画素が四角く見えないよう、周りの 4 画素の濃さから求める。
  - 色にする前に、森林・水域の濃さをそれぞれ補間する。色を補間すると、元の画素より細かく作ったときに輪郭がぼけるため。
  - 森林と水域は、補間した濃さを境目（森林は濃さの半分、水域は約 2 割）から立ち上げて、輪郭を鋭くする。立ち上げる急さは、元の画素が画像の何画素に拡大されるかで決め（上限は森林が 8 倍、水域が 4 倍）、拡大しないときは補間のまま。水域は、川のように 1 画素より細いものがデータの中で薄く（0.1〜0.3 ほど）入っているので、境目を低く、立ち上げをなだらかにして、途切れずに残す。立ち上がりの始まりは、森林は濃さ 0、水域は 0.05 より下にはしない（水域が無い場所や、ごく薄い場所に色が付かないように）。
  - 森林の濃さで地面の色から森林の色へ塗り、水域の色を重ねる。陰影のレイヤーは、選択画面の「陰影を表示」（既定はオフ）をオンにしたときだけ読み、陰影で地面と森林の明るさを変える（水域は変えない）。配色は方位盤用の淡い色（core の `SurfacePalette`）で、地面は方位盤の地面と同じクリーム色。データの無い場所は透明にして、方位盤の地面をそのまま見せる。
  - 画像を作るのは画面を描くスレッドとは別のところで、SQLite は最初に作るときに読み取り専用で開く。
- 地表を表示しているあいだは、距離の帯の色分けを消して同心円の線だけにし、右下の出典に「© ESA WorldCover project 2021・地理院タイルを加工」を添える。
- 「データの出典とライセンス」の画面には、取得済みの地表データのリリース日と出典（manifest の `metadata.sources`）を「地表データ」の見出しの下に出す。
- 確認と取得は `android/core/.../SurfaceData.kt`・`SurfaceDataUpdater.kt` と `ios/YamamukiCore/.../SurfaceData.swift`・`SurfaceDataUpdater.swift`、タイルの座標と合成は `SurfaceTiles`・`SurfaceCompositor`、方位盤用の画像作りは `SurfaceRaster`、SQLite からのタイルの読み出しは `SurfaceTileSource.kt` / `SurfaceTileSource.swift`、画像の持ち方は `SurfaceLayer.kt` / `SurfaceLayer.swift`、保存と SQLite の確認は `SurfaceDataStore.kt` / `SurfaceDataStore.swift` にある。

## 地図（国土地理院）

地表データの代わりに、国土地理院の地理院タイルを方位盤の背景に描ける（開発用のビルドだけ）。地表データの見え方と比べるための試作。

- 地表データの選択画面の「オンラインデータ（国土地理院）」の節に、淡色地図・標準地図・陰影起伏図・色別標高図・写真を並べる（core の `OnlineSurface`）。選ぶとダウンロードせずにすぐ表示する。地表データの行を選ぶと、地図の選択は外れる（設定の `onlineSurface` を空にする）。
- 通信できるときに、表示している周りのタイルだけを取る。方位盤に貼る画像の作り方は地表データと同じで、画像の範囲にかかるタイル（`SurfaceRaster.imageTiles`）をまとめて取り、山と同じ距離と方位の平面図に並べ直す（`SurfaceRaster.renderImage`）。
  - 読むズームは、画像の 1 画素より細かい段のうち最も粗い段。タイルがある最も細かいズームは、淡色地図・標準地図・写真が 18、陰影起伏図が 16、色別標高図が 15。
  - 画素は、透明度を掛けた色で周りの 4 画素から補間する（海などの透明な画素の縁が暗くならないように）。
- 取ったタイルはアプリを開いているあいだだけメモリに覚え（256 枚まで、古く使ったものから捨てる）、拡縮や少しの移動では取り直さない。ファイルには保存せず、オフライン用のキャッシュは持たない。iOS は通信の仕組みのキャッシュも使わない。
- 一度に取るのは 6 枚まで。タイルが無い（404）場所は透明にする。通信に失敗したタイルがあれば、その場所を透明にした画像を貼り、10 秒たってから作り直す。1 枚も取れない（圏外など）ときは前の画像を残し、10 秒ごとに取り直す。地図がまだ無いあいだは、距離の帯の色分けを残す。
- 地図を描いているあいだは、地図の上で読みにくい文字（山名の下の「ほか 3 山」、方位と標高の札、方位盤の上の案内、右下の出典）に、半透明の白い下地（不透明度 0.85）を敷く。山名・距離・方位名の札は、もとから白い下地がある。
- 右下の出典に「地理院タイル」を添え、「データの出典とライセンス」の画面に「背景の地図」の見出しで、出典（国土地理院）と地理院タイル一覧のページ（<https://maps.gsi.go.jp/development/ichiran.html>）を出す。地理院タイルは、リアルタイムに読み込んで表示するなら出典の明示だけで申請は要らない。端末に保存して使う（オフライン用に取っておく）場合の扱いは確かめていない。
- タイルの取得は `OnlineSurface.kt` / `OnlineSurface.swift` の `OnlineSurfaceClient`、画像作りは `SurfaceLayer.kt` / `SurfaceLayer.swift` の `OnlineSurfaceRenderer` にある。
