# 設定

| 項目 | 内容 | 既定 |
|---|---|---|
| フィルター | 「日本百名山」などのグループ（山データの地点のタグ）にチェックを付けると、どれかに入る山だけを表示する。一覧は保存している山データにあるタグから作り、名前順（文字コード順）に並べて山の数を添える。チェックが無いときは、すべての山を表示する。一覧の上の「選択をすべて解除する」で戻せる。山データにタグが無いとき（まだ取得していないときも）は、行を灰色にして押せなくし、「なし」と出す。山データの更新でチェックしたグループが無くなったときは、そのグループでは絞り込まない（チェックは残す） | なし（すべて） |
| 最低標高 | この標高以上の山だけ表示する（0〜3,000m）。絞り込み中は標高不明の山を出さない | 0m（すべて） |
| 表示する山名の上限 | 1 画面に出す山名の数（5〜30）。山名を出さない山はアイコンだけで描く。以前の「最大表示数」で 30 より大きい値にしていたときは 30 になる | 15 |
| 文字の大きさ | 小・標準・大・特大 | 標準 |
| 補助線 | 方位盤に引く線。同心円（距離の円と数字）・方位線（同心円に、45° ごとの方位線と方位名、端末を向けている方向の青い線を足す）・目盛り（同心円の内側に 10° ごとの刻みと 30° ごとの角度の数字を足す）・なし（線と距離の数字を出さず、距離の帯の色分けだけ残す） | 同心円 |
| 起動時の表示距離 | 5〜50km | 15km |
| 画面を常に点灯 | 方位盤の表示中は画面を消さない | オフ |
| 位置と方位の精度 | 省電力・標準・高精度の 3 段階。精度を下げるとバッテリー消費を抑えられるが、現在地や方位の更新頻度も下がる | 標準 |
| 山データの選択 | 選んでいる山データの名前を出す行。押すと、方位盤・検索・出典に使う山データの種類を選ぶ画面（[山データの選択](peak-data.md#山データの選択)）。取得していない種類のダウンロードと、取得済みの種類の削除もここで行う | OpenStreetMap |
| 山データ | 使っている山データの件数・リリース日（データを作った日）・取得日の確認と、取得・最新版の確認 | — |
| 更新を自動で確認 | アプリを開いたときに 30 日に 1 回、新しい山データがあるかを確かめ、あれば方位盤に「新しい山データあり」と出す（ダウンロードは確認してから） | オフ |
| データの出典とライセンス | 使っている山データの出典を見る画面（[データの出典とライセンスの画面](credits-screen.md)） | — |
| 著作権と開発者 | 「このアプリについて」のバージョンの下に、著作権表示（© 2026 The yamamuki Authors）と開発者の名前（Developers: Shohei.S, Hiroyuki.H）を出す。名前は [AUTHORS.md](../AUTHORS.md) と合わせる | — |

設定は端末内（Android は SharedPreferences、iOS は UserDefaults）に保存する。

方位盤は山データを取得せず、保存済みのデータだけで表示する。以前の Overpass からの自動取得、手動取得の更新ボタン、設定の「山データを手動で取得」「取得したデータを使う期間」はなくした。
