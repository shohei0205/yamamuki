# 山の検索と検索位置モード（Android・iOS）

- 右下の検索ボタンで山の検索画面を開く。ヘディングアップと手動位置モードのどちらからでも開ける。
- 山名・よみがな・別名のどれかに、入力した文字を含む山を出す。ひらがなとカタカナ、全角と半角、小さい仮名と大きい仮名(「三ッ峠」と「三ツ峠」、「槍ヶ岳」と「槍ケ岳」)の違いは無視する。
- 結果は「先頭一致」(山名・よみがな・別名のどれかが入力した文字で始まる山)と「部分一致」(途中に含む山)の見出しで分け、先頭一致を先に、それぞれ現在地から近い順に合わせて 50 件まで並べる。標高と現在地からの方角・距離を添える。現在地が分からないときは、それぞれ標高の高い順にする。「や」で槍ヶ岳を探すときに、近くの「〜山(やま)」が先に並ばないようにするため。
- 仮名か英数字 1 文字だけ入力しているときは、部分一致は出さない(多すぎて探しにくいため)。ただし先頭一致が 1 件も無いときは、部分一致を出す。漢字 1 文字なら部分一致も出す。
- 端末に保存している山データだけを探し、通信はしない。山データを取得していないときは、設定画面から取得するよう案内する。
- 設定の「フィルター」で絞り込んでいるときは、選んだグループの山だけから探す。入力欄の下に、絞り込んでいなければ「検索範囲：すべて」、絞り込んでいれば「検索範囲：日本百名山、九州百名山」のように選んだグループを並べて出す。
- 山を選ぶと検索位置モードになる。手動位置モードと同じ操作で、双眼鏡の代わりにその山頂の山頂アイコンを画面の中央に置き(山名は左上の札に出すので、アイコンの横には出さない)、山までの距離と方位もその山頂から測る。地図の向きは選ぶ前の向きのまま止める。
- 検索位置モードでは、左上に手動位置モードの向きの表示の代わりに、選んだ山の札を出す。札は山頂の標識をまねた明るい色の木の横板で、山名と標高、緯度経度を書き、支柱の横の白い小札に端末の向きを出す。向きは手動位置モードの左上の表示と同じく、端末が向いている方位。手動位置モードと見分けられ、そのまま画面を撮っても、どの山から見た方位盤かが分かる。
- 検索位置モードで山をタップすると、詳細の距離は「山頂からの距離」(選んだ山頂から測った距離)として出す。選んだ山頂そのものには距離を出さない。
- 方位盤の山をタップしたときの詳細(まとめた山の一覧から開いたものも)には「山頂へ移動」を出し、押すとその山頂を中心にした検索位置モードに移る。検索から選んだときと同じく、地図の向きはそのときの向きのまま止める。選んだ山頂そのものの詳細には出さない。
- 検索結果やまとめた山の一覧、山の札で標高が分からない山は「標高不明」と出す。
- 検索位置モードには、ヘディングアップと手動位置モードのどちらからでも入れる。検索位置モードで右下のモード切替ボタンを押すと、現在地のヘディングアップに戻る。画面が急に切り替わらないよう、手動位置モードから戻るときと同じく、約 0.5 秒で地図を現在地へ滑らせて端末の向きに回す。アプリを開き直したときは、現在地の方位盤から始める。
