山むき プライバシーポリシー

制定日：2026 年 10 月 7 日

このページは、Android / iOS アプリ「山むき」（以下「本アプリ」）が利用者の情報をどう扱うかを説明するものです。 本アプリは個人（shohei0205）が開発しています。

集める情報と使い道

  • 位置情報：現在地から見える山の方位と距離、現在地の標高を計算するために使います。 計算は端末の中だけで行い、位置情報を開発者やほかの事業者に送ることはありません。端末に保存もしません。
  • 方位センサー（コンパス）の値：端末を向けている方角を知るために使います。端末の中だけで使い、送信も保存もしません。

本アプリには、アカウント登録、利用状況の分析（アナリティクス）、広告、クラッシュレポートの送信の機能はありません。

通信

本アプリは、山頂のデータを取得・更新するときだけ、次のサーバーに接続します。 このとき送るのは、データの取得に必要な情報（アプリの名前と、前回取得したデータの版を確かめる情報）だけで、位置情報や利用者を識別する情報は含みません。

  • GitHub Pages（shohei0205.github.io）：データの版の確認
  • GitHub Releases（github.com）：山頂のデータ本体のダウンロード

通常のインターネットの通信と同じく、接続先のサーバーには端末の IP アドレスなどが記録されることがあります。 これらは GitHub 社が管理しており、その扱いは GitHub のプライバシーに関する声明 に従います。開発者がこの記録を受け取ることはありません。

端末に保存するもの

  • 取得した山頂のデータ（山名・標高・緯度経度）
  • アプリの設定（表示する山の数、文字の大きさなど）

これらは端末の中だけに保存します。山頂のデータは設定画面の「キャッシュ」から消去でき、アプリを削除するとすべて消えます。 アプリの設定は、端末のバックアップ機能（Google のバックアップや iCloud バックアップ）の対象になることがあります。

第三者への提供

本アプリは、利用者の情報を第三者に提供・販売しません。

地図データについて

山頂のデータは OpenStreetMap のデータから作っています （© OpenStreetMap contributors、ODbL）。

このポリシーの変更

機能の追加などで情報の扱いが変わるときは、このページを更新し、制定日の下に改定日を書きます。
