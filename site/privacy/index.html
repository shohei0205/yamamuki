山むき プライバシーポリシー

制定日：2026 年 10 月 7 日
改定日：2026 年 10 月 25 日

このページでは、Android / iOS アプリ「山むき」（以下「本アプリ」）が利用者の情報をどう扱うかを説明します。 本アプリは個人が開発しています。

収集情報と利用法

  • 位置情報：現在地から見える山の方位と距離、現在地の標高を計算するために利用します。 計算は端末の中だけで行います。位置情報を開発者やほかの事業者に送ることはなく、端末に保存することもありません。
  • 方位センサー（コンパス）の値：端末を向けている方角を調べるために利用します。値は端末の中だけで利用し、送信も保存も行いません。

本アプリには、アカウント登録、利用状況の分析（アナリティクス）、クラッシュレポートの送信の機能はありません。

Google Play と App Store で配布する版には、広告を表示します。広告に関わる情報の扱いは、下の「広告」で説明します。

通信

本アプリがサーバーに接続するのは、山頂のデータを取得・更新するとき、新しいデータがあるかを確認するとき、広告を表示するときだけです。 新しいデータの確認は、利用者が操作したときに行います。設定の「更新を自動で確認」をオンにした場合（初期設定はオフ）は、30 日に 1 回、アプリの起動時にも確認します。

山頂のデータの取得と確認で送信するのは、データの取得に必要な情報（アプリの名前と、前回取得したデータの版を確かめる情報）だけです。位置情報や利用者を識別する情報は送りません。 接続先は次の 2 つです。

  • GitHub Pages（shohei0205.github.io）：データの版の確認
  • GitHub Releases（github.com）：山頂のデータ本体のダウンロード

一般的なインターネット通信と同様に、接続先のサーバーには端末の IP アドレスなどが記録されることがあります。 この記録は GitHub 社が管理しており、扱いは GitHub のプライバシーに関する声明 に従います。開発者がこの記録を受け取ることはありません。

広告

Google Play と App Store で配布する版では、画面上部に Google の広告配信サービス「Google AdMob」の広告を表示します。 広告の表示、効果の測定、不正の防止のために、Google が端末から次の情報を直接収集し、利用することがあります。

  • 広告 ID などの端末の識別子
  • IP アドレスと、そこから推定されるおおよその地域
  • 端末とアプリの情報（機種、OS の版、言語など）
  • 広告を表示した記録や、広告をタップした記録

これらの情報は Google が管理しており、扱いは Google のサービスを使用するサイトやアプリから収集した情報の Google による使用 と Google のプライバシーポリシー に従います。 開発者が受け取るのは、広告の表示回数や収益などの集計だけで、利用者を特定できる情報は受け取りません。

  • 本アプリは、GPS などで得た位置情報を広告に渡しません。
  • iOS 版はトラッキングの許可を求めないため、広告識別子（IDFA）は使われません。
  • Android 版では、端末の設定で広告 ID を削除すると、利用者に合わせた広告を表示しないようにできます。

端末に保存するもの

  • 取得した山頂のデータ（山名・標高・緯度経度）
  • アプリの設定（表示する山の数、文字の大きさなど）

これらは端末の中だけに保存します。山頂のデータは設定画面の「キャッシュを消去」で消せます。アプリを削除すると、すべて消えます。 広告を表示するために、Google AdMob が端末に情報を保存することもあります。 アプリの設定は端末のバックアップ機能（Google のバックアップや iCloud バックアップ）の対象になることがあります。

第三者への提供

開発者は、利用者の情報を第三者に提供・販売しません。 ただし、広告を表示するために、「広告」に書いた情報を Google が直接収集することがあります。

地図データについて

山頂のデータは OpenStreetMap のデータから作っています （© OpenStreetMap contributors、ODbL）。
