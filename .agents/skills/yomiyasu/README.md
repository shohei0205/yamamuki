# yomiyasu（コピー）

日本語の文章を推敲するスキル [nanaism/yomiyasu](https://github.com/nanaism/yomiyasu) を、このリポジトリにコピーしたもの。Claude Code と Codex の両方から使う。使い方とこのリポジトリでの注意は AGENTS.md の「言葉づかい」にある。

- 元: nanaism/yomiyasu v1.0.6（コミット `4075fc34fb0333ca1fe42d32cd619338f4a138ba`）の `skills/yomiyasu/` と `LICENSE`
- ライセンス: MIT（`LICENSE`）。コピーするときは `LICENSE` を消さない。
- 中身は直さない。このリポジトリに合わせたい点は AGENTS.md に書く。
- 例外として、`references/` の Markdown には、このリポジトリの決まりに合わせて BOM を付けている（`SKILL.md` には付けない）。

## 版を上げる

本家の新しい版の `skills/yomiyasu/` から `SKILL.md`、`references/`、`scripts/` を、ルートから `LICENSE` を上書きし、`references/` の Markdown に BOM を付け直す。上の版とコミットも書き換える。
